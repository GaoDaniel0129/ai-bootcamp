# python-basics

Python 基础与工程实践练习仓库（56 天 AI 工程师冲刺 · W1-W2）

## 项目结构
- week1/ledger —— 命令行记账（JSON 持久化，模块化拆分练习）
- week2/day9_class —— 类与对象：BankAccount / Student
- week2/day10_decorator —— 装饰器与生成器手写练习
- week2/day12_sql —— SQLite：建表 / CRUD / JOIN
- week2/contacts —— 通讯录命令行工具（SQLite 存储，W2 验收项目）

## 运行方法
\`\`\`bash
cd week2/contacts
python main.py add 张三 13800138000   # 添加联系人
python main.py list                   # 列出全部
python main.py search 张              # 模糊搜索
\`\`\`

## 已掌握技能
- Python：模块化、类与对象、装饰器、生成器、推导式
- 数据：SQLite CRUD / JOIN / 参数化查询
- 工具：Git 分支管理、venv 虚拟环境、DBeaver
